# VELORA — Fashion Store

Fashion e-commerce store website for Laiba.

- 12 products (Women, Men, Shoes, Accessories) with PKR prices
- Live search, category filters and sorting
- Quick-view with size / quantity selection, wishlist
- Slide-in cart with quantity controls, free delivery over Rs 5,000
- Promo codes: WELCOME10 (10% off), SALE20 (20% off)
- Checkout with COD / card / bank transfer, order confirmation
- Responsive, light / dark mode

Open `index.html` to view the store.
